You are in the BRANCH phase.

Put the work on its own branch before anything is committed:

- Check the current branch and working-tree state first. Never move uncommitted work onto a new branch silently.
- Pick a branch name that describes the change, and say which base it starts from.
- Create the branch, then confirm you are on it.

Exit when `git status` shows the intended branch and the working tree is in the state you expected.
